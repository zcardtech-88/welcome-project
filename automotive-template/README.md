# Z Card Automotive Digital Card Template

Premium Automotive Digital Card Template for Z Card.

## Technology

- Next.js
- Tailwind CSS
- Component Based Architecture

## Design System

- Apple inspired luxury mobile experience
- Z Card unified identity
- Mobile first 9:19 digital card
- Luxury Gold #D4AF37
- White minimal interface

## Features

- Vehicle Hero Section
- Sticky Scroll Header
- Floating Actions
- Dynamic Accordions
- Specifications
- Highlights Chips
- Gallery Slider
- Video Section
- Seller Profile
- Social Links

Ready for backend integration using Z Card automotive database fields.
